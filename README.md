# Листва — интернет-магазин комнатных растений

Учебный проект: адаптивный интернет-магазин комнатных растений на чистом HTML, CSS и JavaScript.
Три страницы (главная, каталог, карточка товара) и выезжающая панель корзины.

**Опубликованный сайт:** _[добавить ссылку на GitHub Pages / Netlify]_

## Технологии

- HTML5 — семантическая разметка (`header`, `nav`, `main`, `section`, `footer`), без ошибок в [validator.w3.org](https://validator.w3.org/);
- CSS3 — Grid, Flexbox, переменные в `:root`, mobile-first, БЭМ в именовании классов;
- JavaScript (ES6+) — модули на глобальных объектах: данные, корзина, каталог, карточка товара, общий интерфейс;
- Google Fonts — Cormorant Garamond (заголовки) и Onest (текст), файлы подключены локально из `fonts/`;
- Инлайновые SVG-иконки (в духе Lucide) — без внешних библиотек;
- Никаких фреймворков, сборщиков и зависимостей: сайт открывается как статические файлы.

## Как запустить

Вариант 1 — просто открыть `index.html` в браузере (данные лежат в `js/products.js`, `fetch` не используется).

Вариант 2 — локальный сервер (нужен, если захотите проверить поведение в разных браузерах):

```bash
# Python
python -m http.server 8000

# или Node
npx serve .
```

После запуска откройте `http://localhost:8000`.

## Что умеет

**Главная.** Первый экран, три преимущества, четыре популярных растения, подбор по освещению
(плитки ведут в каталог с уже включённым фильтром), форма подписки с проверкой почты на JS.

**Каталог.** Хлебные крошки, счётчик найденного, фильтры по размеру, освещению, уходу и цене,
сортировка по популярности и цене, поиск по названию, кнопка «Показать ещё», пустое состояние.
Состояние фильтров отражается в адресной строке — ссылкой можно поделиться:
`catalog.html?light=shade&sort=price-asc`.

**Карточка товара.** Галерея с миниатюрами, выбор размера горшка с доплатой, счётчик количества,
вкладки «Описание / Уход / Доставка» без перезагрузки, блок похожих растений.
Если в адресе несуществующий `?id=` — понятное сообщение со ссылкой в каталог.

**Корзина.** Выезжающая панель справа: добавление, удаление, изменение количества, итоговая сумма,
подсказка «До бесплатной доставки осталось X ₽», оформление заказа, пустое состояние.
Закрывается крестиком, кликом по фону и клавишей Esc, пока открыта — страница не прокручивается.
Состояние хранится в `localStorage` и переживает перезагрузку. Одинаковый товар с одинаковым
размером горшка не дублируется, а увеличивает количество.

## Адаптив и доступность

- Mobile-first, брейкпоинты 360 / 768 / 1024 / 1280 px, контейнер 1200 px;
- горизонтальной прокрутки нет ни на одной ширине от 360 px;
- видимый фокус (`:focus-visible`), управление с клавиатуры, включая вкладки (стрелки) и меню (Esc);
- у полей есть подписи, у изображений — `alt`, у динамических сообщений — `aria-live`;
- контраст текста не ниже AA, семантические теги, `skip link` к содержимому.
